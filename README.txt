
SMARTMART PYTHON ANALYTICS DASHBOARD

TECH STACK
- Python
- Flask
- Pandas
- HTML
- CSS
- Chart.js

HOW TO RUN

1. Install Python

2. Open terminal in project folder

3. Install requirements

pip install -r requirements.txt

4. Run project

python app.py

5. Open browser

http://127.0.0.1:5000/
